# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com)

## [Unreleased]

## [0.0.0.a6] - 2026-11-24
### Added
- Добавлена команда справки `genplib help`

## [0.0.0.a5] - 2026-11-16
### Added
- Добавлена команда `version` в подгруппе set - заменяет версию библиотеки в pyproject.toml
- Добавлена команда `description` в подгруппе set - заменяет описание библиотеки в pyproject.toml
- Добавлена подгруппа `set dependencies` для изменения зависимостей с командами add (добавление) и pop (удаление)
### Changed
- улучшена инициализация библиотеки `genplib init`

## [0.0.0.a4] - 2026-11-15
### Added
- Добавлена группа команд **genplib set**
- Так-же добавлена команда в подгруппе **set**: `name`, изменяющая имя библиотеки в pyproject.toml, а так-же название директории с кодом библиотеки (из старого названия в новое)

## [0.0.0.a3] - 2026-11-15
### Added
- Добавлено создание папки с кодом проекта (библиотеки)
- Добавлена проверка на то, пустое ли название вводимое при создании библиотеки
### Changed
- Обновлен pyproject.toml - добавлен `build-backend` в `[build-system]` и поле `packages`

## [0.0.0.a2] - 2026-11-14
### Added
- Добавлена функция init создающая файл pyproject.toml в текущей директории
- Добавлена команда genplib init создающая в текущей директории pyproject.toml с вашими настройками, но если в текущей директории УЖЕ существует файл pyproject.toml то скрипт спрашивает нужно ли перезаписывать
### Changed
- Изменен .gitignore - добавлено исключение `sandbox/` (тестирование скрипта в отдельной папке автором)
- Теперь для установки библиотеки помимо Typer требуется так-же библиотека tomlkit
- В [README](README.md) теперь расписана инструкция как установить библиотеку а так-же что уже в ней реализовано
